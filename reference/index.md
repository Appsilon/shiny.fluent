# Package index

## General

Functions that help with building a UI, but are not components.

- [`fluentPage()`](https://appsilon.github.io/shiny.fluent/reference/fluentPage.md)
  : Basic Fluent UI page
- [`fluentPeople`](https://appsilon.github.io/shiny.fluent/reference/fluentPeople.md)
  : A dataset of sample people based on Fluent UI examples
- [`fluentSalesDeals`](https://appsilon.github.io/shiny.fluent/reference/fluentSalesDeals.md)
  : A randomly generated dataset of imaginary sales deals
- [`parseTheme()`](https://appsilon.github.io/shiny.fluent/reference/parseTheme.md)
  : parseTheme
- [`runExample()`](https://appsilon.github.io/shiny.fluent/reference/runExample.md)
  : Run example shiny.fluent apps.
- [`shinyFluentDependency()`](https://appsilon.github.io/shiny.fluent/reference/shinyFluentDependency.md)
  : Shiny Fluent JS dependency
