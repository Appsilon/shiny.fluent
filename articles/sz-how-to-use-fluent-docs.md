# Topic guide: Using Fluent components documentation

You have several options for accessing the Fluent UI documentation.

If you’re trying to find a suitable component or want to see what’s
available, we recommend one of the two options:

1.  Browse the official [Fluent UI
    docs](https://developer.microsoft.com/en-us/fluentui#/controls/web).
2.  Run the showcase app with `shiny.fluent::runExample("dashboard")`.

To get information on a specific component, e.g. `Toggle`, you can:

1.  Use the R help system:
    [`?Toggle`](https://appsilon.github.io/shiny.fluent/reference/Toggle.md).
2.  Browse the
    [reference](https://appsilon.github.io/shiny.fluent/reference/index.md)
    on this site.
3.  Find the component in the official [Fluent UI
    docs](https://developer.microsoft.com/en-us/fluentui#/controls/web/toggle).
